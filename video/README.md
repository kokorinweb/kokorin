# Движок вертикальных роликов

Ролики 1080x1920 собираются из JSON-сценария и рендерятся в MP4 через
[Remotion](https://www.remotion.dev/) — то есть кадр это React-компонент, а не
проект в After Effects. Правится кодом, рендерится из терминала, повторяется
одинаково от ролика к ролику.

## Команды

```bash
npm install
npm run studio                                  # превью с таймлайном, localhost:3000
npx remotion render Reel out/demo.mp4 --props=scripts/demo.json
```

В контейнере без своего Chrome:

```bash
export REMOTION_BROWSER_EXECUTABLE=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell
```

## Сценарий

Один ролик — один JSON. Файл в `scripts/`, отдаётся рендеру через `--props`.

```json
{
  "mascotPlaceholder": true,
  "script": {
    "id": "demo",
    "fps": 30,
    "audio": null,
    "scenes": [
      {
        "text": "Всё, что длится дольше ==300 мс==, ощущается как **тормоза**.",
        "pose": "point",
        "broll": { "type": "bignum", "value": "300 мс", "label": "предел" }
      }
    ]
  }
}
```

Разметка в тексте:

| Запись | Что делает |
|---|---|
| `**слово**` | белым и жирным — смысловое ударение |
| `==слово==` | в лаймовой плашке — термин, цифра, название |

Соседние слова внутри одной пары `==...==` попадают в одну плашку.

## Блоки B-roll

Верхняя треть кадра. Один блок на сцену, поле `broll`.

| `type` | Поля | Для чего |
|---|---|---|
| `bignum` | `value`, `label?` | крупная цифра: `82+`, `300 мс` |
| `code` | `file`, `lines[]` | блок кода с шапкой-именем файла |
| `terminal` | `command`, `title?` | команда, печатается посимвольно |
| `list` | `items[]` | список пунктов, вылетают по очереди |
| `badge` | `icon`, `label?`, `tone?` | иконка в квадрате + подпись |
| `shot` | `src`, `caption?` | скриншот из `public/` |
| `strike` | `text`, `note?`, `noteTone?` | зачёркнутое красным + пометка |
| `chips` | `items[]` | ряд мелких плашек |
| `none` | — | пустой кадр, только субтитр |

Иконки для `badge`: `lock`, `check`, `clipboard`, `shield`, `cursor`, `arrow`,
`spark`, `warning`.

## Озвучка и тайминг

Без звука длительность сцены считается по длине слов — темп настраивается
в `src/script/parse.ts`, константа `PACE`.

Со звуком работает `tools/voice.mjs`: он озвучивает каждую сцену отдельно,
меряет длину полученного mp3, записывает её в сцену как `durationInSeconds`
и склеивает дорожку целиком. Тайминги слов внутри сцены растягиваются под
её реальную длину, поэтому отдельное выравнивание распознаванием не нужно.

```bash
export TTS_PROVIDER=openai OPENAI_API_KEY=...   # или elevenlabs
node tools/voice.mjs scripts/skills.json
npx remotion render Reel out/skills.mp4 --props=scripts/skills.json
```

Свой голос вместо синтеза: `TTS_PROVIDER=files`, а записи сцен положить в
`public/voice/<id>/00.mp3`, `01.mp3` и так далее. Скрипт их не тронет,
только измерит и склеит.

Нужны `ffmpeg` и `ffprobe` в PATH.

Если у сцены есть пословные тайминги, они главнее всего остального:

```json
"words": [{ "word": "Всё,", "start": 0.0, "end": 0.42 }]
```

## Человечек

Персонаж нарисован вектором в `src/components/guy/` и позируется параметрами,
а не набором картинок. Поэтому пропорции, свет и лицо не «плывут» от позы к
позе — то, на чём обычно ломается сгенерированный пак иллюстраций.

| Файл | Что в нём |
|---|---|
| `guy/parts.ts` | палитра, опорные точки фигуры, таблица поз |
| `guy/Face.tsx` | брови, веки, рот — семь выражений |
| `guy/Guy.tsx` | сборка, дыхание, моргание, реакция на смену позы |

Позы: `idle`, `point`, `shrug`, `explain`, `think`, `stop`, `facepalm`,
`happy`, `wave`, `thumbup`, `victory`, `cross`, `shock`. Выражение лица
привязано к позе — отдельно его задавать не нужно.

Новая поза — это одна строка в `POSES`: две кривые рук, форма кистей,
выражение и наклон головы. Лист всех поз рендерится из `scripts/poses.json`.

Надпись на футболке — поле `shirt` в сценарии. Персонажа можно выключить
целиком: `"mascot": false`.

Если однажды появится нарисованный пак — PNG кладутся в `public/mascot/`
и прописываются в `src/components/poses.ts`, они перебивают вектор.

## Что настраивается

| Что | Где |
|---|---|
| Цвета, размеры, положение блоков | `src/theme.ts` |
| Темп речи, длина строки субтитра | `src/script/parse.ts` |
| Новый тип B-roll | `src/components/broll/index.tsx` |
| Иконки | `src/components/Icon.tsx` |

## Сценарии

| Файл | О чём |
|---|---|
| `scripts/skills.json` | скиллы: как перестать объяснять агенту одно и то же |
| `scripts/tests.json` | почему вайбкодинг разваливается без тестов |
| `scripts/design.json` | почему все ИИ-сайты выглядят одинаково |
| `scripts/demo.json` | демо на все типы блоков |
| `scripts/poses.json` | лист поз человечка |
